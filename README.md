# HPDFViewer — Public Assets

Pagine pubbliche dell'app Android HPDFViewer, servite con GitHub Pages:

- `privacy.html` — informativa privacy (it + en), da indicare in Play Console
- `app-ads.txt` — dichiarazione AdMob (sostituire `pub-XXXXXXXXXXXXXXXX` con il publisher ID)

Sorgente: `distribution/site/` nel repo dell'app.
